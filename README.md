# Brushye

A free, open-source painting, illustration and comics app for Windows, macOS and Linux.
It follows the workflow and panel organization of Clip Studio Paint 1.13.2, with original
visual design. Everything is scriptable: every action is a replayable command, and the app runs headless.

**Status:** planning (Phase 1). No application code yet. See [ROADMAP.md](ROADMAP.md),
[FEATURES.md](FEATURES.md) and [DECISIONS.md](DECISIONS.md).
