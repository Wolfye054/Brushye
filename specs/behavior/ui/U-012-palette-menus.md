stroke preview · ✓Show command bar — Hide Tool property: <sub tool> palette.

preset of current size — Hide Brush size: <sub tool> palette.

Color Slider palette · Show Color Mixing palette · Show Color History palette · Show Approximate

(The first group is specific to the active tab; the rest lists every palette of the group,
"Hide" for the active one and "Show" for the others.)

## Layer Property

## Layer
The Layer menu's first four groups (New Raster Layer … Flatten image, as in U-002 and the row
context menu) — Thumbnail size ▸ · Thumbnail display settings ▸ · ✓Show property bar(K) ·
✓Show command bar · Set command bar below list(Q) — Hide Layer palette · Show History palette ·
Show Auto Action palette.

## Pattern
Each ≡ menu has three parts:
1. The palette's own commands.
2. Display toggles (command bar, property bar, preview).
3. A final group that hides this palette and shows each other palette in the same tab group.

## What Brushye should match
These menus, in this order, for each palette: Brushye's commands where they exist (disabled
otherwise), the display toggles it supports, and the Hide/Show palette group.
